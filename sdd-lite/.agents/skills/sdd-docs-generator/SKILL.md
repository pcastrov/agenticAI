# SDD Docs Generator (Lite)

Lee solo la plantilla necesaria en `references/`:
- `spec-template.md` — activo unificado (máx ~150 líneas)
- `summary-template.md` — foto + scratchpad (máx ~100)
- `history-shard-template.md` — un shard `h-NN.md` (máx ~150)
- `history-archive-template.md` — compactado frío

Idioma: español. IDs estables. Mover a history al cerrar; compactar shards viejos (máx 3 recientes).
